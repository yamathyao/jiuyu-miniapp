# 方庭九屿下一步操作建议

> 本文用于承接当前 UI 收口后的下一阶段工作，帮助后续继续推进时不必重新梳理上下文。

## 当前完成面

当前仓库已经完成以下能力：

- 微信小游戏入口与 `js/` 主线结构稳定
- 首页默认启动，支持 `继续游戏 / 开始新局 / 难度选择 / 设置`
- 独立设置页与独立语言页已接入
- 简体中文 / 英文双语切换已接入主流程
- 提示与检查已按难度分级
- 首页、设置页、语言页、棋盘页头部已经统一为一套轻量国风页眉
- 棋盘页右上角 `设置` 入口已接入
- `node --test tests/game-engine.test.js` 当前为通过状态

## 下一步优先级

建议按下面顺序继续：

1. 首页主体留白与纵向节奏
2. 棋盘页工具栏视觉统一
3. 完成页
4. 统计页
5. 更外层的回访与长期留存能力

## 推荐下一步一：首页主体留白与纵向节奏

目标：

- 继续收首页主按钮、难度区、设置入口和底部状态文案之间的垂直节奏
- 减少“区块虽齐但有些偏散”的感觉
- 让首页更像一个被完整设计过的入口页，而不是多个功能块上下堆叠

建议动作：

- 重新审视首页从品牌区到主按钮的留白距离
- 微调主按钮与难度区之间的节奏
- 进一步压缩底部状态文案的视觉存在感
- 必要时让 `设置` 入口和状态文案形成更清晰的主次关系

验证：

- 手工检查首页纵向节奏是否更稳定
- 回归 `node --test tests/game-engine.test.js`

## 推荐下一步二：棋盘页工具栏视觉统一

目标：

- 让数字区和工具区更明确地融入当前这套温润国风体系
- 缩小“页眉已经很统一，但下方操作区仍偏旧”的断层

建议动作：

- 根据 `playful / pro` 两组主题继续区分按钮质感
- 数字区强化统一的牌面感或温润卡面感
- 工具区减少旧样式中的现代扁平感
- 保持工具栏命中区与现有交互逻辑不变

验证：

- 手工检查棋盘页整体一致性
- 回归 `node --test tests/game-engine.test.js`
