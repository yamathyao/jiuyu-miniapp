# 方庭九屿设置入口与分级视觉重构设计

## 背景

方庭九屿当前已经具备：

- 首页基础入口
- 继续游戏 / 新开一局
- 难度选择
- 棋盘主界面
- 提示与检查分级
- 中英文双语切换

但当前 UI 仍存在三个明确问题：

1. 棋盘主界面没有清晰的 `设置` 入口
2. 首页使用“内嵌展开”的设置方式，信息层级混乱，不适合继续扩展
3. 整体视觉还不够精致，未形成与难度分级一致的气质表达

本轮要把这三个问题一起解决，并正式建立一套与难度分级绑定的双风格 UI 体系。

## 目标

- 棋盘主界面补上可见、易点按的 `设置` 入口
- 首页不再承担“展开式设置面板”，改为纯入口页
- 新增独立 `设置页`
- 在设置页中新增独立 `语言页`
- 首页、设置页、语言页、棋盘页形成清晰闭环
- `beginner / intermediate` 与 `skilled / expert` 共享结构、区分气质
- 整体风格向更精致的国风 / 水墨方向提升

## 非目标

- 不引入真正的多页面路由框架
- 不新增复杂转场动画系统
- 不新增统计页、成就页、排行榜页
- 不改变提示 / 检查的算法逻辑
- 不翻译品牌名 `方庭九屿`

## 信息架构

本轮采用四个场景状态：

- `home`
- `settings`
- `language`
- `board`

状态关系如下：

- 启动后默认进入 `home`
- `home -> board`
- `home -> settings`
- `settings -> language`
- `settings -> home`
- `language -> settings`
- `board -> settings`
- `settings -> board`（若从棋盘进入设置，则返回棋盘）

这里不引入独立路由器，只在 `main.js` 中维护一个轻量 `activeScreen` 与来源状态即可。

## 页面职责

### 首页 `home`

首页是启动后的主入口页，只负责承接核心开始动作，不再内嵌设置内容。

页面包含：

- 品牌标题 `方庭九屿`
- 副标题
- `继续游戏`
- `开始新局`
- 四档难度选择
- `设置` 入口
- 当前状态轻提示

规则：

- 有存档时，`继续游戏` 为主按钮
- 无存档时，`开始新局` 为主按钮
- 难度选择始终留在首页，作为最直接的开局决策入口

### 设置页 `settings`

设置页是独立场景，不再以内嵌面板形式出现。

页面包含：

- 页面标题
- 返回入口
- `语言` 设置项
- 当前语言摘要
- 当前难度摘要
- 轻量说明文案

本轮设置页保持克制，不堆砌额外功能。它的核心作用是：

- 承接主界面和棋盘界面的统一设置入口
- 作为后续扩展更多设置项的稳定容器

### 语言页 `language`

语言选择单独成页，避免在首页或设置页里塞过多控件。

页面包含：

- 页面标题
- 返回入口
- `简体中文`
- `English`
- 当前选中状态

交互规则：

- 点击任一语言立即切换
- 立即持久化到 `settings.language`
- 当前页立即重绘
- 返回设置页后应展示新的语言摘要

### 棋盘页 `board`

棋盘页保持数独主操作区角色，但顶部结构要更完整。

页面新增：

- 右上角小型 `设置` 按钮

页面保留：

- 品牌标题
- 当前难度
- 反馈区
- 棋盘
- 数字区
- 工具区

## 布局设计

### 首页布局

从上到下：

1. 品牌区
2. 主操作区
3. 难度选择区
4. 次级入口区
5. 底部状态区

原则：

- 品牌区不贴顶部，保留更充足留白
- 主操作按钮是第一视觉焦点
- 难度选择是第二焦点
- `设置` 作为次级入口，不与主按钮抢权重

### 设置页布局

从上到下：

1. 顶部栏：返回 + 标题
2. 设置卡片区
3. 底部说明区

设置项采用单列卡片式布局，避免过于像系统表单，保持游戏内统一气质。

### 语言页布局

从上到下：

1. 顶部栏：返回 + 标题
2. 两个语言选项卡
3. 当前生效说明

语言选项卡采用可点击的大卡片，而不是小单选点，保证触控体验。

### 棋盘页布局

从上到下：

1. 顶部信息区
2. 棋盘
3. 数字区
4. 工具区

调整重点：

- 棋盘整体下移
- 顶部信息区容纳品牌、难度、反馈和 `设置`
- 数字区与工具区保留立体按压感

## 视觉方向

本轮采用两套气质，不改骨架，只改表现层。

### A 组：`beginner / intermediate`

定位：

- 游戏化国风
- 更亲和
- 更轻快
- 更有陪伴感

视觉特征：

- 背景接近暖纸色、米杏色
- 强调色可用胭脂、桃粉、竹青、小面积金砂
- 模块边角更柔和
- 按钮有明显但柔和的立体层次
- 装饰可少量使用云纹、印章感、浅纹理

情绪目标：

- 让新手感到“欢迎进入”“可以慢慢来”

### B 组：`skilled / expert`

定位：

- 专业
- 简洁
- 干练
- 水墨雅致

视觉特征：

- 背景接近宣纸白、雾灰、淡墨青
- 强调色以黛青、墨灰、冷灰蓝为主
- 装饰比 A 组更少
- 线条更克制
- 留白更充分
- 按钮立体感保留，但转为硬朗、整洁的压层感

情绪目标：

- 让高难度用户一进入就感到专注、冷静、利落

## 组件风格要求

### 按钮

首页主按钮、首页次按钮、工具按钮、数字按钮都继续采用立体感，但要区分两组质感：

- A 组：偏柔和、像彩釉木牌或印章牌面
- B 组：偏克制、像压纹纸牌或细边砚台感

不做厚重 3D，不做现代玻璃拟态。

### 卡片

设置项与语言项采用卡片承载：

- A 组卡片更温润
- B 组卡片更清透克制

### 顶部标题区

品牌名始终保留 `方庭九屿`，不翻译。

不同难度只调整：

- 副标题语气
- 字重
- 配色
- 背景衬托

## 交互细则

### 首页

- 点击 `继续游戏`：进入当前存档对局
- 点击 `开始新局`：按当前选中难度创建新局并进入棋盘
- 点击难度卡：更新当前 `preferredDifficulty`
- 点击 `设置`：进入设置页

### 设置页

- 点击返回：回到来源页面
- 点击 `语言`：进入语言页

来源规则：

- 若从首页进入，则返回首页
- 若从棋盘进入，则返回棋盘

### 语言页

- 点击语言卡：立即切换语言并持久化
- 点击返回：回到设置页

### 棋盘页

- 点击右上角 `设置`：进入设置页
- 进入设置页时保留当前棋盘状态，不清空反馈和存档

## 状态与数据

本轮新增或明确以下状态：

- `activeScreen`
- `settingsEntrySource`
- `language`
- `selectedDifficulty`

其中：

- `settingsEntrySource` 仅用于判断设置页返回到 `home` 还是 `board`
- `language` 与 `selectedDifficulty` 仍走现有设置持久化逻辑

## 文案与翻译要求

本轮新增页面文案也必须统一进入 i18n：

- 设置页标题
- 语言页标题
- 返回文案
- 语言摘要文案
- 当前难度摘要文案
- 轻量说明文案
- 棋盘页 `设置` 按钮文案

品牌 `方庭九屿` 继续保持不翻译。

## 技术落点

建议在现有结构上做增量扩展：

- `main.js`：扩展场景状态切换与来源管理
- `js/scene/home-scene.js`：去掉内嵌设置展开逻辑，改为纯首页
- `js/scene/board-scene.js`：增加顶部 `设置` 按钮绘制与命中
- 新增 `js/scene/settings-scene.js`
- 新增 `js/scene/language-scene.js`
- `js/ui/theme-policy.js`：补足两套风格所需颜色与层次变量
- `js/i18n/locales.js`：补设置页和语言页相关文案

## 验证要求

至少验证以下行为：

1. 启动默认进入首页
2. 首页可切换四档难度
3. 首页 `设置` 可进入设置页
4. 设置页 `语言` 可进入语言页
5. 语言切换后立即生效并持久化
6. 棋盘页右上角 `设置` 可进入设置页
7. 从棋盘进入设置后返回，能回到棋盘
8. `beginner / intermediate` 与 `skilled / expert` 呈现不同主题气质
9. 原有继续游戏、新开一局、提示、检查、工具栏不被破坏

## 风险与约束

- 当前项目仍是单文件主循环驱动，场景状态增加后要避免把 `main.js` 变成不可维护的大分支
- 需要控制新增 scene 的职责边界，避免首页、设置页、语言页重复持有业务状态
- 视觉升级要控制在 Canvas 现有绘制能力内，不引入过重装饰导致维护成本失控

## 结论

本轮采用 A 方案：

- 首页负责开始与难度选择
- 设置页独立承载设置入口
- 语言页独立承载语言切换
- 棋盘页补上 `设置` 入口
- 难度分两组呈现“游戏化国风”和“水墨雅致”两套风格

这条路径能够同时解决结构清晰度、设置可扩展性和视觉精致度三个问题，并且能在现有代码结构上用增量方式落地。
